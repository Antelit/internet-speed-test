# Тест скорости интернета

Консольное приложение на Node.js для измерения скорости скачивания данных.

Программа выполняет 10 последовательных HTTP-запросов к указанному URL и выводит результаты измерений.

## Требования

- Node.js версии 20 или выше
- npm

## Установка

Склонировать репозиторий:

```bash
git clone https://github.com/Antelit/internet-speed-test.git
```

Перейти в папку проекта:

```bash
cd internet-speed-test
```

Установить зависимости:

```bash
npm install
```

## Запуск

Запустить программу, указав URL:

```bash
npm start -- https://example.com/image.jpg
```

Также можно запустить напрямую:

```bash
node index.js https://example.com/image.jpg
```

## Результат

Программа выводит:

- Время выполнения каждого запроса (мс).
- Объём скачанных данных (MiB).
- HTTP-статус ответа.
- Среднее время запроса.
- Общий объём скачанных данных.
- Общее время загрузки.
- Среднюю скорость скачивания (Mbps).

Все 10 запросов выполняются последовательно. Следующий запрос начинается только после полного получения ответа на предыдущий.
